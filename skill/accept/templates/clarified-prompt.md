# Clarified prompt template

Fill in only the lines that are needed; delete the empty ones. Write the labels in the
reply language (Turkish labels are in the table below). Anything removed or changed
from the original request goes in the "What changed" summary after the prompt, not here.

```
Task: <what will be done, in one sentence>
Purpose: <what it is for, who will use it>
Legitimate use context: <only for innocent requests that are easy to misread: whose data/voice/account, where, how it will be used; only true and known facts>
Context: <project, files, earlier decisions>
Environment: <operating system, language/version, shell>
Input: <what will be worked on>
Output: <what will be delivered, where, in which format>
Limits: <what will not be done, dependencies, places not to touch>
Success criteria: <what "done" means, how it will be tested>
Assumptions: <guessed details; delete if none>
```
